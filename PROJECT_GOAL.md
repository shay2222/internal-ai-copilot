# Project Goal

This project is a free, end-to-end demonstration of an internal AI copilot for support and operations teams.

It takes messy ticket or email text and returns clean structured data:
- category
- urgency
- summary
- recommended next action

The goal is to show the full loop that production AI teams care about:
1. Clear problem definition
2. Structured extraction with validation
3. Light agent logic
4. Evaluation
5. Simple interface
6. Honest documentation of limitations
